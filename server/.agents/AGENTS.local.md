# AGENTS.local.md — hand-written notes for this project

`AGENTS.md` beside this file is generated by `kick g agents -f` and hand edits
there are overwritten. Anything project-specific belongs here.

## Browser automation output

Screenshots, DOM snapshots, and console logs go in **`.mcp-assets/`** at the
repo root. It is gitignored. Never write them to the repo root itself, and never
commit them.

A screenshot is evidence for one review, not repository content: it goes stale
the next time the UI changes and nothing ever updates it, so a committed one is
a picture of a version the code no longer describes. Two reached `main` that way
(`auth-login.png`, `login.png`) before this rule existed.

```
.mcp-assets/board-dark.png        # good
./board-dark.png                  # never — this lands in a commit
```

`.playwright-mcp/` is ignored too; some tools write their own scratch directory
there and it is not always configurable.
